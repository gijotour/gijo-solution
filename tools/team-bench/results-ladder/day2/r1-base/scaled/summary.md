## 0. 먼저 — 지시받은 플래그 꼴이 이 빌드에서 안 된다

지시문은 `extra: ["--lora-scaled", "<gguf>", "<scale>"]`(세 인자)였는데, 이 빌드는 **한 인자 `FNAME:SCALE`** 꼴이다.

```
$ ~/gijo-as/server/llama.cpp-next/build/bin/llama-server --help | grep -A2 -- --lora-scaled
--lora-scaled FNAME:SCALE,...           path to LoRA adapter with user defined scaling (format:
                                        FNAME:SCALE,...)
                                        note: use comma-separated values
```
(빌드 `0.3.0-dev (build 1, commit 0eadefe)` · aarch64)

그대로 썼으면 `<scale>`이 위치 인자로 흘러 **조용히 무시되거나 기동이 죽었을** 자리다. 그래서 `["--lora-scaled", "<gguf>:<scale>"]`로 바꾸고, **세기가 실제로 먹었는지**를 매 회전 `GET /lora-adapters`로 받아 파일에 남겼다.

```
0.75/lora-adapters.json → [{"id":0,"path":".../adapter.gguf","scale":0.75,...}]
0.5 /lora-adapters.json → [{... "scale":0.5 ...}]
0.25/lora-adapters.json → [{... "scale":0.25 ...}]
```

## 6. 판정 — 물음 셋에 대한 답

**① 어느 세기에서 12과제 평균이 기준선 0.867로 돌아오는가**
**@0.25에서 0.867 — 기준선과 같아지지만 「초과」는 아니다.** 0.75·0.50은 못 돌아온다(0.850·0.842). 세기와 평균이 단조롭지도 않다(0.850 > 0.842).

**② 그때 인용 20자겹침이 남는가**
**20자겹침은 다섯 점 전부 1로 한 번도 안 흔들렸다.** 정찰이 지적한 잣대 결함이 이 판에서 그대로 재현됐다 — 관문 ②는 회귀를 원리상 못 본다. 실제로 흔들린 값은 **「인용」**(1→0→0→0→**1**)이고, 그것이 `glossary_cite` 1.00→0.70→…→**1.00**을 만든다. **@0.25에서만 복구된다.**

**③ 창작 「원문:」이 사라지는가**
**사라진다. 5 → 2 → 1 → 0(@0.25).** 세기에 대해 단조 감소하는 유일한 지표다.

**종합.** 형식 붕괴(답 눌림·인용 실종·「원문:」 창작)는 **어댑터 세기의 함수가 맞다** — 세기를 낮추면 셋 다 풀리고, @0.25에서 기준선 수준으로 돌아온다. 그런데 **@0.25는 어댑터가 준 유일한 이득도 함께 잃는다**: `scan_messy` 0.50→0.86이 어댑터가 올린 하나뿐인 과제인데 세기를 내리면 기준선 0.50으로 되돌아간다. 즉 이 어댑터에는 **「형식을 안 깨면서 뭔가를 얻는 세기」가 없다** — 0.25는 사실상 어댑터를 끄는 것에 가깝고(평균·인용·길이 모두 기준선 복귀, 이득 0), 그 위로 올리면 형식이 깨진다. **세기 조절로는 회전 1을 살릴 수 없다. 데이터(RAFT 구성)를 고쳐야 한다** — 정찰이 짚은 대로 「근거 없음/모른다」 시연 행 0건 · 답 평균 224자 · 「원문:」 꼬리표 53.6%가 그대로 학습된 결과다.

## 7. 이 숫자를 믿을 때의 한계 (정직하게)

- **표본 1회·temperature 0**이다. 그런데도 흔들리는 자리가 있다: `scan_messy`가 @1.00 0.86 ↔ 나머지 0.50, `ti_trap` 오탐 2↔3. **0.02~0.05 차이는 잡음과 못 가른다** — 0.850(@0.75)과 0.842(@0.50)의 우열을 단정하지 않는다.
- **@1.00은 이번에 다시 재지 않고 회전 1 파일을 그대로 썼다.** 그때는 `--lora`, 이번 세 점은 `--lora-scaled …:S`다. scale 1.0에서 둘이 같아야 하지만 **실측으로 확인하진 않았다.**
- **KEV 3/3 관문은 기준선도 못 넘는다**(기준선 prompt 2/3). 이 관문으로는 어떤 어댑터도 합격할 수 없다 — 정찰의 잣대 결함 지적이 이 판에서 재확인됐다.
- `needle_64k`는 다섯 점 전부 400(ctx 초과)이라 평균에서 뺐다. `ti_trap`은 다섯 점 전부 0이라 세기를 가르는 정보가 없다.
- 한글 비율이 세기에 대해 단조롭지 않다(0.762 → 0.735 → 0.752). 표본 1회의 흔들림으로 보인다.
