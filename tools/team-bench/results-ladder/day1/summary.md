## 8. 이 폴더에 무엇이 있나

| 파일 | 무엇 |
|---|---|
| `<주제>-<번호>.json` | 회차 보고서 — **끝난 회차의 유일한 증거**(로그는 시작할 때 생긴다) |
| `<주제>-<번호>.log` | 회차 진행 로그(조각별 소요·실패 사유 원문) |

| `approve-<주제>-<시각>.json` | 사슬 밖에서 손으로 돌린 승인 결과 |
| `사내규정-01.crash.log` · `사내규정-01.aborted-2015.log` | 죽은 회차의 흔적(점이 둘인 이름 = 어떤 셈에도 안 걸린다) |
| `summary.md` | 이 문서 |

### ⚠ 로그(`*.log`)는 저장소에 안 들어간다
`.gitignore:55`의 `*.log`가 전부 막는다(크기 문제가 아니다 — 다 합쳐 98KB다).
그래서 `위협대응-01.log`(오류 118건의 원문)·`사내규정-01.crash.log`·`사내규정-01.aborted-2015.log`는
**win 이 폴더에만** 있고 다른 기계에서 clone 하면 안 보인다.
저장소 전역 규칙을 이 자리에서 임의로 뚫지 않았다 — **넣을지는 사장님 결정**이다
(넣으려면 `git add -f` 또는 `tools/team-bench/results-ladder/**/*.log` 예외 한 줄).
왜 값이 있나: 회차 보고서(`.json`)에 안 남는 것이 로그에 있다 — 조각별 소요 시간, 실패 조각의 ref,
중단 회차의 `편입 40/40` 같은 중간 셈(이 문서의 123건이 거기서 나왔다).

⚠ **승인의 「왜」는 `*.approve.json`에만 있다.** 서버 감사는 「학습 후보 결정 / 승인 / <id>」만 적는다
(`approve-distill.mjs` 머리 주석). 그래서 이 파일들을 저장소에 함께 커밋한다 — 지우면 근거가 사라진다.
