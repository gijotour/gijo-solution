03

무엇을 어디서 만들고 · 어디서 재나

제품이 도는 환경에서 잰다
무엇어디서왜
서버 시험WSL · bash tools/wsl-test.sh제품이 WSL에서 돈다. 실측 27초/2,979개 vs Windows 14분/파일. Windows에서 재면 딴 환경을 검증한다.
클라 빌드·게시·실화면Windows(exe) / Mac(dmg)electron-builder·CDP가 거기 묶여 있다. 게시는 Windows 전용.
ARM CUDA 실측GB10 · ssh gb10Pro/올인원이 실제로 돌 맨바닥. x86 CUDA·Metal에서는 원리상 못 잰다.
git ls-files·이미지 시험Windows 호스트WSL 사본은 git 저장소가 아니고 이미지를 안 가져간다.
