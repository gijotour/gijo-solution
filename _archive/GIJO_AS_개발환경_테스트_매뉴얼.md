```
                    WireGuard VPN (10.8.0.x)
```

| 구성 요소 | 상태 | 비고 |

| OpenSSH 서버 (Windows :22) | ✅ | VPN 대역(10.8.0.0/24)만 허용, Mac 공개키 등록(비번 없이 접속) |

| Mac 올인원 | ✅ | Metal llama.cpp + bge-m3 + 채팅모델 2종 + 운영 데이터(RAG·온톨로지) 이식 완료 |
| 정방향 배포 | ✅ 실증 1회 | `tools/deploy-prod.ps1` — 테스트 914개 게이트 통과해야 운영 반영 |

- 제품 로그인(내 테스트용): `claude-deploy` — 비번은 Windows 사용자 환경변수 `GIJO_ADMIN_PASSWORD` (repo에 평문 금지 · CLAUDE.md). 양쪽 서버 DB에 존재.
- 운영 서버: `http://10.8.0.1:4000` (또는 Windows에서 localhost:4000) · Mac 서버: `http://10.8.0.11:4000`

## 2부. 직접 테스트 매뉴얼 (순서대로, 약 30~40분)

각 항목의 **[기대 결과]** 와 다르면 그 내용을 그대로 Claude(어느 쪽이든)에게 붙여넣으면 됩니다.

### T1. VPN·연결 기본 확인 (2분)
1. Mac: WireGuard 앱에서 터널 **켜짐** 확인, "최근 핸드셰이크"가 2분 이내인지
2. Mac 터미널: `ssh user@10.8.0.1 "echo OK"`
- **[기대]** 비밀번호 없이 `OK` 출력. (안 되면: WireGuard 토글 껐다 켜기)

### T2. Mac 올인원 서버 확인 (5분)
1. Mac 터미널: `curl -s http://localhost:4000/api/health`
- **[기대]** `"ok":true` + schema 13
2. **Windows 클라이언트(GIJO AS 앱)** 실행 → 로그인 화면에서 **서버 주소를 `http://10.8.0.11:4000`으로 변경** → 본인 계정(jyh)으로 로그인
- **[기대]** 대시보드 상단에 "연동 서버 10.8.0.11:4000 · 운영중 · 로컬 모델 2개 로드"
3. 보안 분석 > 보안 KPI 열기
- **[기대]** 종합 태세 47 · 열린 취약점 313 · 자산 16 — **운영과 같은 숫자** (= 데이터 이식 성공의 눈 확인)

### T3. Mac에서 AI 기능 확인 (5분) — T2에서 Mac 서버에 로그인한 상태로
1. 아무 화면에서 챗봇에 한국어 질문: 예) "열린 취약점 현황 요약해줘"
- **[기대]** 수 초 내 한국어 응답 (merged-lily 모델, M1 Max Metal 구동)
2. 지식 질문: 예) "KISA 취약점 조치 절차 알려줘"
- **[기대]** 이식된 지식베이스 문서를 근거로 답변 (RAG 생존 확인)
3. 응답 체감 속도 메모 — 끊기며 느리게 나오면 알려줄 것 (기대: 초당 25~40토큰)

### T4. ⭐ 핵심: Mac 개발 → 운영 배포 사이클 (10분)
실제로 코드를 고쳐서 운영까지 보내보는 리허설. Mac Claude Code에게 이렇게 시키세요:
> "배포 사이클 테스트야. 서버에 무해한 수정 하나 해줘 — 예: /api/health 응답에 "deployTest":"m1" 필드 추가. 커밋하고 git push hub 까지."
그 다음 Mac 터미널에서 **배포 한 줄**:
```bash
ssh user@10.8.0.1 "powershell -NoProfile -ExecutionPolicy Bypass -File 'd:/Connect AI/tools/deploy-prod.ps1'"
```
- **[기대]** 화면에 1/5~5/5 단계가 흐르고: 테스트 914개 통과 → BUILD_OK → killed (PID) → `HEALTH OK` → `✅ 배포 완료`
- 확인: Windows에서 `curl http://localhost:4000/api/health` (또는 브라우저) → `"deployTest":"m1"` 보이면 **운영 반영 성공**
- ⚠ 배포 순간 운영 접속자(본인 앱 포함) 세션이 끊길 수 있음 — 재로그인하면 됨
- 마지막으로 원복: Mac Claude에게 "deployTest 필드 제거하고 다시 배포"

### T5. 역방향: Windows 개발 → Mac 반영 (5분)
1. Windows Claude(저)에게: "역방향 테스트용 무해 수정 하나 커밋하고 hub push 해줘"
2. Mac 터미널: `cd ~/gijo-as && ./tools/update-dev-mac.sh`
- **[기대]** pull → 빌드 → 재시작 → `✅ HEALTH OK`
- 확인: Mac 서버에서 수정 내용 반영 확인 (Mac Claude에게 시켜도 됨)

### T6. 오늘 게시된 클라이언트 2.7.15 기능 (5분) — 운영 서버(10.8.0.1:4000)로 로그인
1. 보안 KPI 화면: 첫인상이 임원 요약만(태세+핵심 6카드+AI 보안+접힌 "📂 상세 지표")인지
2. 상단 카드(예: 열린 취약점) 클릭 → "리포트를 출력할까요?" → 예 → 생성 후 리포트 화면 이동
3. AI 보안 타일 4개 각각 클릭 → 자산허브/AI-BOM/레드팀 화면으로 이동
4. 📂 상세 지표 펼침 → 9개 섹션, 각 섹션 타일/"→ 화면 열기" 클릭 → 해당 화면 이동
- **[기대]** 위 동작 전부. 접힘 상태는 다음 방문 때 기억됨

### T7. 마무리 점검 (3분)
1. Windows 앱을 **운영 서버(localhost:4000)** 로 되돌려 로그인 (T2에서 바꾼 주소 원복!)
2. Mac WireGuard는 개발할 때만 켜도 됨 (연결 자체는 자동 재수립)

## 3부. 알려진 주의사항 (테스트 중 만날 수 있는 것)

| 증상/상황 | 설명 |
|---|---|
| 배포 직후 앱이 로그아웃됨 | 정상 — 운영 재시작으로 세션 초기화. 재로그인 |
| Mac에서 ssh/scp에 경로 공백 | `d:/Connect\ AI/...` 백슬래시 이스케이프 사용 (따옴표 중첩은 실패) |
| Mac 서버 "pro 티어 권장" 배지 | 32GB 기준 코드상 정상 표시지만 **standard 유지 권장** (macOS가 메모리 공유) |
| Mac 자동 시작 모델 = merged-lily | 정상 — 운영 DB의 "마지막 사용 모델" 승계. 한국어 실측 최고 모델이라 유지 권장 |
| Mac 서버 JWT 시크릿 경고 | 개발기라 무방. 실사용 승격 시 `GIJO_JWT_SECRET` 설정 |
| `data.fresh-backup` (Mac) | 이식 전 개발 데이터 백업 — 테스트 다 끝나면 삭제 가능 |
| Mac·운영 데이터는 서로 독립 | Mac은 이식 시점의 사본. 운영에 쌓이는 새 데이터는 Mac에 자동 반영 안 됨(원하면 재이식) |
| UAC 필요한 작업 | 방화벽/터널/서비스 변경은 관리자 승인("예") 필요 — Claude가 창을 띄우면 눌러주면 됨 |
