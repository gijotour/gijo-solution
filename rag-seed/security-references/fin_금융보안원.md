# 금융보안원(FSI, Financial Security Institute)
- 정체: 2015년 설립된 금융권 통합 보안 전담기관. 영문명은 Financial Security Institute(FSI)이며 금융감독원(FSS)과 다르다.
- 역할: 금융권 통합보안관제, 침해사고 대응·정보공유(금융ISAC 운영), 취약점 분석·평가·모의해킹, 금융보안 정책·연구, 금융분야 위협 인텔리전스 제공.
- 침해사고 신고 체계: 금융회사는 전자금융사고 발생 시 전자금융거래법 등에 따라 금융위원회·금융감독원에 보고하고, 금융보안원(금융ISAC)과 침해 정보를 공유·공동 대응한다. 개인정보 유출이 동반되면 개인정보보호위원회·KISA 신고 절차도 병행한다.
- 담당자 요약: "금융보안원=Financial Security Institute, 금융권 관제·침해대응(금융ISAC). 사고는 금융위·금감원 보고 + 금융보안원 공유."
