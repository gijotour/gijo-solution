# CIS 벤치마크(CIS Benchmarks)
- 정의: CIS(Center for Internet Security)가 전문가 합의로 만든 시스템별 보안 설정 기준(하드닝 가이드).
- 대상: OS(Windows/Linux), 클라우드(CIS AWS/Azure/GCP Foundations Benchmark), DB, 웹서버, 컨테이너·쿠버네티스 등.
- 레벨: Level 1(운영 영향 적은 기본 보안), Level 2(고보안·심화, 일부 기능 제약 감수).
- CIS Controls와 구분: Controls는 18개 통제 항목의 상위 프레임워크, Benchmarks는 제품별 구체 설정값.
- 활용: CSPM·취약점 스캐너·Config 규칙으로 벤치마크 준수율을 자동 점검하고, 미준수 항목을 하드닝. ISMS-P·규제 점검의 기술 근거로 매핑.
- 담당자 요약: "CIS 벤치마크=제품별 보안설정 표준(Level1/2). 클라우드는 CIS Foundations로 자동 점검·하드닝."
