# [보안 솔루션 규격 및 매뉴얼] Imperva DSF (Data Security Fabric) + DAM + FAM + DRA (Imperva [외산])

- **솔루션 분류**: DSP / DSPM / DAG (외산)
- **공급사 / 제조사**: Imperva [외산]
- **도입 대상 및 주무 부서**: 데이터베이스(DB)와 파일 시스템
- **솔루션 핵심 역할**: 데이터베이스(DB)와 파일 시스템 전체를 대상으로 "누가, 언제, 어떤 데이터에 접근하여 무슨 행위를 했는지"를 실시간 감시하고, UEBA(사용자 행위 분석) 기반으로 데이터 오남용 및 유출 위협을 탐지·차단하는 데이터 중심 보안
- **표준 조달/도입 단가**: ₩75,000,000
- **ISMS-P 인증 통제항목**: 2.5 데이터 거버넌스 및 감사

---

## 1. 솔루션 개요 (Overview)
정형 DB(DAM) 및 클라우드 S3/Blob(FAM)에 대한 사용자 접근 쿼리 및 파이프라인 접근을 머신러닝 UEBA로 실시간 감시 및 차단하는 데이터 센트릭 솔루션

## 2. 도입 목적 및 필요성 (Purpose)
전사 하이브리드 데이터 인프라 및 리스크 제어
- 정형 DB 데이터(AWS RDS, Oracle, MS-SQL 등) 활동 감시(DAM) 
- 비정형 파일 데이터(AWS S3, Azure Blob, NAS, Slack 등) 활동 감시(FAM)
- 권한 오용, 우회 정상 로그인을 통한 대량 데이터 반출 사전 탐지
- 데이터 자산의 무단 접근, 변경, 삭제 등 비정상 행위 모니터링

## 3. 핵심 기능 (Key Features)
정형/비정형 통합 자산 식별 (DDC)
- 멀티 클라우드 저장소와 DB 내 개인정보 탐지 및 분류
데이터 활동 모니터링 (DAM/FAM)
- SQL 쿼리, 파일 접근/변경/삭제 이력 실시간 감사 및 강제 차단
데이터 리스크 분석 (DRA)
- 데이터 컨텍스트 기반의 UEBA(행동분석) 엔진 가동 및 위험 스코어링
단일 패브릭(DSF) 통합 가시성
- 분산 데이터 소스를 허브 구조로 묶어 단일 대시보드로 통합

## 4. 특장점 및 차별화 요소 (Highlights)
정상 계정을 위장한 우회 유출을 잡는 머신러닝 UEBA 
- 단순 접근 권한 제어(DB 접근제어) 툴의 한계를 극복하여, 정상 로그인 사용자가 짧은 시간 동안 비정상적으로 많은 수의 DB에 접근하는 다중 쿼리 행위를 감지

## 5. 컴플라이언스 및 법적 규제 준수 (Regulation)
개인정보보호법, 정보통신망법 및 글로벌 규제(GDPR, HIPAA 등)
- 금융·공공권의 데이터 접근 이력에 대한 실시간 로깅 및 실시간 활동 모니터링 의무 충족
- 고유식별정보 데이터의 자동 검색 및 중요도 분류 컴플라이언스 이행

## 6. 도입 기대 효과 (Expected Effects)
내부자 위협 및 계정 탈취에 의한 대형 개인정보 유출 원천 차단

## 7. 실무 운영 매뉴얼 & 점검 절차 (Operation Manual)
- **일일 점검**: 엔진 데몬 프로세스 상태 확인, 관리 콘솔 대시보드 경보(Alert) 로그 확인.
- **주간 점검**: 정책 위반 및 차단 건수 통계 추출, 에이전트/노드 버전 무결성 점검.
- **월간 점검**: 관리자 접근 감사 로그 백업, 암호화 키 및 만료 주기 점검, ISMS-P 증적 자료 추출.
- **장애 대응 런북**:
  1. 관리 콘솔 접속 불가 시 데몬 서비스(Service / Systemd) 상태 확인 및 프로세스 재기동.
  2. 네트워크 차단 지연 발생 시 Bypass 모드 전환 및 세션 테이블 임계치 확인.
  3. 라이선스 만료 경고 시 조달/유지보수 담당 엔지니어 긴급 기술지원 티켓 인계.
