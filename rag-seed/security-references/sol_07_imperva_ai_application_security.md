# [보안 솔루션 규격 및 매뉴얼] Imperva AI Application Security (Imperva [외산])

- **솔루션 분류**: WAAP (Web Application & API Protection) 내의 GenAI 보안 모듈 (외산)
- **공급사 / 제조사**: Imperva [외산]
- **도입 대상 및 주무 부서**: 자사 서비스 앱(챗봇, API, LLM 연동 앱)
- **솔루션 핵심 역할**: 외부 사용자의 Prompt Injection / Jailbreak 방어
- **표준 조달/도입 단가**: ₩38,000,000
- **ISMS-P 인증 통제항목**: 2.4 웹/API 보안 취약점 통제

---

## 1. 솔루션 개요 (Overview)
자체 서비스 중인 LLM API 및 챗봇 앱으로 들어오는 악성 프롬프트 인젝션 및 과도한 토큰 유발 공격(DoW)을 전면 차단하는 모듈

## 2. 도입 목적 및 필요성 (Purpose)
자체 개발 AI 서비스 (외부 연동 API 및 자체 LLM 챗봇 안전성 확보)
- OWASP Top 10 for LLM 애플리케이션 위협 차단
- 공격자의 악성 프롬프트 인젝션 및 시스템 프롬프트 우회 탈취 방어
- AI 답변을 통한 사내 민감 데이터 유출 원천 방지

## 3. 핵심 기능 (Key Features)
실시간 양방향 프롬프트 가드레일
- 사용자의 질문(Prompt)과 AI의 답변(Response) 전체 트래픽을 실시간 감시·통제

프롬프트 인젝션 및 Jailbreak 방어
- AI 시스템의 권한을 무력화하거나 우회 지시를 내리는 악의적인 문자 패턴 탐지 및 전면 차단


민감 정보 답변 유출 차단
- AI가 오작동하여 기업 소스코드, 고객 정보(PII)를 답변에 포함할 경우 실시간 마스킹 및 차단

Denial of Wallet
- 무차별 대입 질문을 던져 사내 AI API 과금 비용(Token 비용)을 폭탄처럼 유발하는 공격을 제한(Rate Limit)

## 4. 특장점 및 차별화 요소 (Highlights)
양방향 실시간 컨텍스트 검사
- 사용자 질문(Inbound)의 악의적 우회 패턴(프롬프트 인젝션, Jailbreak)뿐만 아니라, LLM이 생성한 답변(Outbound) 내 개인정보(PII)나 사내 핵심 소스코드 유출까지 양방향으로 실시간 마스킹 및 통제합니다.

## 5. 컴플라이언스 및 법적 규제 준수 (Regulation)
금융보안원 「인공지능 보안 안내서」
AI 사용자의 프롬프트 입력값과 AI의 답변을 실시간 감시하여 개인정보 유출 및 적대적 입력(Jailbreak)을 차단해야 함.

-> 자체 운영 챗봇 API의 프롬프트와 LLM 출력 답변(Response)을 양방향 모니터링하여 가이드라인 내 'AI 안전성 검증 및 비정상 오작동 방지' 요건 충족.

## 6. 도입 기대 효과 (Expected Effects)
대고객 AI 비즈니스의 안정적인 가동 보장

- 해킹 공격으로 인한 AI 서비스 장애, 시스템 명령어 노출, 악성 우회 답변 생성 등의 비즈니스 신뢰도 실추 사고 사전 예방

- 불필요하거나 반복적인 대량 API 호출(DoW 공격)을 방어하여 불필요하게 낭비되는 AI API 사용료(클라우드 비용) 절감

## 7. 실무 운영 매뉴얼 & 점검 절차 (Operation Manual)
- **일일 점검**: 엔진 데몬 프로세스 상태 확인, 관리 콘솔 대시보드 경보(Alert) 로그 확인.
- **주간 점검**: 정책 위반 및 차단 건수 통계 추출, 에이전트/노드 버전 무결성 점검.
- **월간 점검**: 관리자 접근 감사 로그 백업, 암호화 키 및 만료 주기 점검, ISMS-P 증적 자료 추출.
- **장애 대응 런북**:
  1. 관리 콘솔 접속 불가 시 데몬 서비스(Service / Systemd) 상태 확인 및 프로세스 재기동.
  2. 네트워크 차단 지연 발생 시 Bypass 모드 전환 및 세션 테이블 임계치 확인.
  3. 라이선스 만료 경고 시 조달/유지보수 담당 엔지니어 긴급 기술지원 티켓 인계.
