# 다단계 인증(MFA) 우선 적용 대상
- 우선순위(높은 순): (1) 관리자·특권 계정(도메인/시스템 관리자, 클라우드 루트·IAM 관리자, DBA), (2) 인터넷에 노출된 원격 접근(VPN, SSH/RDP, 웹 관리자 콘솔), (3) 이메일·협업·SSO(IdP) 계정(피싱·계정탈취 파급이 큼), (4) 재무·인사·개인정보 취급 시스템 계정, (5) 개발/운영 파이프라인(코드 저장소·CI/CD·클라우드 콘솔).
- 원칙: 권한이 크거나 외부에서 접근 가능한 계정일수록 우선. 특권 계정은 MFA를 필수화하고, 가능하면 피싱 저항(FIDO2/보안키)·OTP를 우선하며 SMS는 보조로만.
- 담당자 요약: "관리자·특권 계정과 인터넷 노출 원격접근·SSO부터. 피싱 저항 방식(FIDO2) 우선, SMS는 보조."
