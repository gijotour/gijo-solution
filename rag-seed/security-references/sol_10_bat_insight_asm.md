# [보안 솔루션 규격 및 매뉴얼] BAT Insight ASM (NSHC [국산])

- **솔루션 분류**: ASM / AI-EASM (AI 기반 외부 공격 표면 관리) (국산)
- **공급사 / 제조사**: NSHC [국산]
- **도입 대상 및 주무 부서**: 인터넷에 노출된 기업의 IT 자산(IP, 서브도메인, 포트, Web/API, 미관리 Shadow IT 등)
- **솔루션 핵심 역할**: 자산 자동 발굴, 위협/취약점 스캔, 위협 인텔리전스 연계 분석 및 선제적 대응
- **표준 조달/도입 단가**: ₩26,000,000
- **ISMS-P 인증 통제항목**: 2.3 외부 위협 인텔리전스 통제

---

## 1. 솔루션 개요 (Overview)
8단계 자동화 스캔 파이프라인을 가동하여 인터넷 노출 지점(IP, 서브도메인, SSL 등)을 탐지하고 CVSS+EPSS 기반 우선순위를 평정하는 시스템

## 2. 도입 목적 및 필요성 (Purpose)
전사 외부 노출 자산의 통합 가시성 확보
- 보안팀이 인지하지 못한 서버, 도메인, 클라우드 리소스 식별
- 인터넷 연결 포트, 서비스, SSL/TLS 인증서 만료 추적  - 그림자 IT(Shadow IT), 오설정, 미인가 자산 통제
- 실제 악용 가능성 기반 위협의 조치·보고 자동화

## 3. 핵심 기능 (Key Features)
- CVSS + EPSS 기반 정밀 위협 분석
- 기술적 심각도와 향후 30일 내 실제 악용 확률(0~100%) 연동 우선순위화  Shadow IT 자산 통제 워크플로우
- 미식별 후보 검토(Pending/Confirmed 등) 단계별 자산 전환 관리  멀티 LLM Security Advisor- OpenAI, Anthropic, 로컬 LLM 연동을 통한 자연어 조치 방안 생성

## 4. 특장점 및 차별화 요소 (Highlights)
엔터프라이즈급 독자적 스캔 및 위협 정량화
- 타사처럼 외부 도구 단순 연동이 아닌, Rustscan, Nmap, Nuclei, Katana 등을 병렬 실행하여 대규모 스캔 성능 최적화 (Comprehensive 스캔 약 30분)  - 글로벌 Shodan, Censys API 연동 및 Tor 익명 네트워크 스캔, CVE 룰 생성기 등 독보적인 오펜시브 실험실 모듈 탑재

## 5. 컴플라이언스 및 법적 규제 준수 (Regulation)
ISMS-P 인증 항목 및 정부/금융권 내부통제 지침 준수
- 정보통신망법에 따른 정기적 기술적 취약점 분석·평가 대응
 - SSL/TLS 인증서 만료 및 취약 설정 규제 수립 지침 준수

## 6. 도입 기대 효과 (Expected Effects)
보안 사각지대 제로화 및 운영 비용 절감
- 보안팀이 몰랐던 임시 개발 서버, 만료 도메인, 클라우드 오설정 자산을 자동으로 식별해 공격 표면 최소화
- CVSS+EPSS 자동 매핑과 AI 자연어 조치 가이드로 보안 담당자의 위협 선별 및 대응 소요 시간 대폭 단축

## 7. 실무 운영 매뉴얼 & 점검 절차 (Operation Manual)
- **일일 점검**: 엔진 데몬 프로세스 상태 확인, 관리 콘솔 대시보드 경보(Alert) 로그 확인.
- **주간 점검**: 정책 위반 및 차단 건수 통계 추출, 에이전트/노드 버전 무결성 점검.
- **월간 점검**: 관리자 접근 감사 로그 백업, 암호화 키 및 만료 주기 점검, ISMS-P 증적 자료 추출.
- **장애 대응 런북**:
  1. 관리 콘솔 접속 불가 시 데몬 서비스(Service / Systemd) 상태 확인 및 프로세스 재기동.
  2. 네트워크 차단 지연 발생 시 Bypass 모드 전환 및 세션 테이블 임계치 확인.
  3. 라이선스 만료 경고 시 조달/유지보수 담당 엔지니어 긴급 기술지원 티켓 인계.
