# [보안 솔루션 규격 및 매뉴얼] SooJi.Bee (수지비) (인더포레스트 [국산])

- **솔루션 분류**: ASM / AI-EASM (AI 기반 외부 공격 표면 관리) (국산)
- **공급사 / 제조사**: 인더포레스트 [국산]
- **도입 대상 및 주무 부서**: 미관리 외부 IT 자산(Shadow IT), 노출 포트, 유출 계정, 외부 IP/도메인
- **솔루션 핵심 역할**: 외부 자산 식별, 1-Day CVE 침투 가능성 자동 검증, 다크웹 TI 수집, 위협 우선순위화
Automated PenTesting (자동화된 침투 테스트/BAS)
- **표준 조달/도입 단가**: ₩22,000,000
- **ISMS-P 인증 통제항목**: 2.3 자산 식별 및 공격표면 관리

---

## 1. 솔루션 개요 (Overview)
외부 인터넷 및 다크웹에 노출된 미관리 자산과 유출 계정을 식별하고, 1Day CVE 자동 침투 시뮬레이션을 수행하는 공격 표면 검증 솔루션

## 2. 도입 목적 및 필요성 (Purpose)
공격자 관점의 직접적인 위협 노출 검증  
- OSINT, 딥웹, 다크웹 유출 임직원 계정 식별
- 미관리/미승인 자산 및 외부 열린 Risky 포트 진단
- 노출/유출 계정 기반의 자동 로그인 가능 여부 검증
- 최신 1Day CVE 취약점에 대한 실질적 Exploit 자동 테스트

## 3. 핵심 기능 (Key Features)
양방향 위협 정보 수집 및 상시 검증
- OSINT, 딥웹, 다크웹 통합 검색 및 평판 조회  자동화 침해 진단 (Validation)
- 알려진 1Day CVE 자동 테스트 및 크레덴셜 스터핑 검증  원클릭 자동 이행 점검
- 조치된 항목에 대한 자동 이행 점검 테스트 가동  전문가 수동 검증 서비스 연계
- 수집된 위협 기반 침투 경로 분석 전문가 레포트 제공 (연 1회 등)

## 4. 특장점 및 차별화 요소 (Highlights)
EASM에 자동 '모의침투 검증'을 결합한 특허 기술
  - 단순 자산 나열(Risks)을 넘어, 실제 질문/답변 데이터 및 우회 로그인 성공 여부(Issues)를 증적 화면 캡처로 입증하는 상시 실효성 검증 제공
- 업무협업 Wiki/Git 내 소스코드 하드코딩 정보 노출 추적 탁월
- 대한민국 우수 특허 대상(1위) 수상 및 검증된 Offensive Security 전문가 노하우 반영

## 5. 컴플라이언스 및 법적 규제 준수 (Regulation)
과기정통부·KISA 공공 중소/중견기업 ASM 취약점 점검 지침 준수
- 정부의 전사 IT 자산 인터넷 접점 식별 및 긴급 보안점검 요건 만족
- 가트너 CTEM(지속적 위협 노출 관리) 프레임워크 준수

## 6. 도입 기대 효과 (Expected Effects)
사전·사후 침해 유입 경로   차단
- 매년 수행하는 1회성 진단의 한계를 극복하고 연간 상시 가상 RED 팀 가동 효과 구현
- 유출된 임직원 계정이 사내 2FA 미적용 구멍을 통해 실제 로그인되는 경로를 선제 제거하여 랜섬웨어 예방

## 7. 실무 운영 매뉴얼 & 점검 절차 (Operation Manual)
- **일일 점검**: 엔진 데몬 프로세스 상태 확인, 관리 콘솔 대시보드 경보(Alert) 로그 확인.
- **주간 점검**: 정책 위반 및 차단 건수 통계 추출, 에이전트/노드 버전 무결성 점검.
- **월간 점검**: 관리자 접근 감사 로그 백업, 암호화 키 및 만료 주기 점검, ISMS-P 증적 자료 추출.
- **장애 대응 런북**:
  1. 관리 콘솔 접속 불가 시 데몬 서비스(Service / Systemd) 상태 확인 및 프로세스 재기동.
  2. 네트워크 차단 지연 발생 시 Bypass 모드 전환 및 세션 테이블 임계치 확인.
  3. 라이선스 만료 경고 시 조달/유지보수 담당 엔지니어 긴급 기술지원 티켓 인계.
