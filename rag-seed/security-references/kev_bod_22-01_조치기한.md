# KEV 조치 기한 — CISA BOD 22-01 근거
- KEV(Known Exploited Vulnerabilities): 미국 CISA가 실제 공격에 악용 확인된 취약점만 모은 목록.
- 근거 지침: CISA 구속력 있는 운영지침 BOD 22-01(2021-11-03). 미 연방기관은 KEV 목록의 각 취약점을 CISA가 지정한 "조치 기한(due date)"까지 반드시 제거해야 함.
- 통상 기한: 목록에 새로 추가된 취약점은 보통 약 2주(14일). 과거에 공개됐던 취약점이 뒤늦게 등재되면 약 6개월을 주기도 함(항목별로 CISA가 명시).
- 민간·기업 권고: 법적 의무는 아니지만 KEV는 사실상 최우선 조치 기준. 인터넷 노출 자산은 15일 이내, 내부 자산도 30일 이내 조치를 SLA로 두는 것이 모범사례.
- 담당자 요약: "KEV면 무조건 최우선. 기한은 CISA 지정일(대개 2주) 기준, 노출 자산일수록 더 빨리."
