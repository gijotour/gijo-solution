# SIEM 상관분석 규칙(Correlation Rule)
- 정의: 서로 다른 출처의 로그·이벤트를 시간·주체·자산 기준으로 엮어(상관), 단일 이벤트로는 안 보이는 공격 시나리오를 탐지하는 규칙.
- 구성 요소: 조건(어떤 이벤트가), 상관 키(같은 사용자/출발지 IP/호스트), 시간창(예: 5분 내), 임계값(횟수), 예외(화이트리스트), 대응(알림·티켓·차단).
- 예시:
  - 무차별 대입: 같은 계정/출발지에서 인증 실패 N회 후 성공 1회 → 계정 탈취 의심.
  - 불가능한 이동(impossible travel): 짧은 시간에 지리적으로 먼 두 위치에서 동일 계정 로그인.
  - 권한상승+외부통신: 관리자 권한 부여 직후 비정상 외부 연결.
  - 스캔 후 접속: 포트스캔 탐지 뒤 같은 출발지에서 서비스 접속 성공.
- 담당자 요약: "여러 로그를 주체·시간으로 엮어 시나리오를 탐지. 조건+상관키+시간창+임계값으로 규칙화."
