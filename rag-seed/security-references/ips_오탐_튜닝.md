# IPS 오탐(False Positive) 튜닝 절차
- 1) 확인: 차단 로그에서 시그니처 ID, 출발지/목적지, 페이로드를 확인해 정상 업무 트래픽인지 실제 공격인지 구분.
- 2) 임시 완화: 확실한 오탐이면 해당 시그니처를 특정 출발지/목적지에 한해 예외(화이트리스트) 또는 탐지(alert)-only로 전환. 시그니처 전체를 끄지 말고 범위를 좁혀 예외 처리.
- 3) 모니터링: 일정 기간(예: 수일) 관찰해 오탐 재발·부작용 여부 확인.
- 4) 정식 반영: 검증되면 정책에 반영하고 변경 이력·사유를 기록. 벤더 시그니처 업데이트로 개선되는지 추적.
- 원칙: 오탐을 줄이되 실제 공격을 놓치지 않도록 "차단→탐지 전환"과 "범위 축소"를 우선하고, 시그니처 비활성화는 최후 수단.
- 담당자 요약: "시그니처를 통째로 끄지 말고 출발지/목적지 범위로 예외 처리→관찰→정식 반영. 변경 이력 기록."
