# Smart MD — 보안 실업무 템플릿 (초안)

Smart MD는 별도 제품이라 최종 반영은 그 레포에서 — win 조율. 여기 파일은 형식·문구 초안이다.

## 설계 원칙 (실업무 맞춤)
- Smart MD 강점 활용: **화면 캡처 Ctrl+V 증적** 자리를 본문에 명시.
- 비밀번호·키는 문서에 안 적게(인수인계·점검 모두 명시) — GIJO 보안 원칙과 일치.
- 규제 숫자는 **참고 요약 + "법령 판례 조회에서 원문 확인"** 안내(지어내기 방지).
- GIJO 연동 표기: 저장 → **나만의 자료** 폴더 → RAG 반영 → **AI 챗**이 답. 「쓰기→쌓임→물어보기」 루프.
- 장비 등록부·나만의 연락처와 상호 참조(자산·담당자).
