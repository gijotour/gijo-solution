# /GIJOAS인계 — 작업 마무리 · 상대 머신 인계

이 머신에서의 작업을 마무리하고 반대편 머신(Windows↔Mac)으로 넘긴다. 다음을 순서대로:

1. `git status --short` — 커밋 안 된 작업 변경이 있으면 프로젝트 컨벤션(한국어 커밋 메시지, 왜/무엇 중심)으로 커밋한다. 무엇을 커밋할지 애매하면 사용자에게 확인.
   - 커밋 제외 대상: server-dist 산출물, data/·models/ 실데이터, mac 전용 네이티브 부산물(darwin binding 등), .tmp/스크래치.
2. **server/ 를 건드렸으면 `npm test` 실행** — 실패하면 push 금지, 실패 내용 보고 후 중단.
3. **의존성 변경 확인(자동)** — 사람 기억에 맡기지 말고 실제로 본다:
   ```
   git diff --name-only <직전 인계 커밋>..HEAD -- server/package.json client/package.json
   ```
   바뀌었으면 인계 블록 「주의사항」에 **반드시** 적는다:
   `⚠ server 의존성 변경 — 받는 쪽에서 npm ci 먼저 (안 하면 테스트가 통째로 실패한다)`
   - ⚠ 2026-08-09 실사고: `better-sqlite3-multiple-ciphers`가 추가됐는데 인계에 안 적혀,
     Mac에서 **275개 시험 파일이 전부 실패**했다. 원인을 코드에서 찾느라 시간을 썼다.
     「주의사항」이 사람이 손으로 적는 빈칸이라 그냥 빠졌다 — 그래서 확인을 명령에 박는다.
   - 배포 명령(/GIJOAS배포)에는 같은 확인이 이미 있다. 인계에만 없었다.
4. **올린다 — 어디로 올릴지는 머신과 상황에 따라 다르다. `git remote`로 실제 확인하고 고른다:**
   - **공동작업 브랜치 작업 중이면**(제임스와 함께 하는 일) → `git push origin <브랜치>` 후 **PR을 연다**.
     main에 직접 push하지 않는다. `GIJO_AS_공동작업_가이드.md` 참조.
   - `hub`가 있고 혼자 하는 작업이면 → `git push hub main`
   - `hub`가 없으면(외부 협업자 머신) → `git push origin <브랜치>` + PR. **origin이 유일한 통로다.**
4. 마지막에 **아래 형식의 "인계 블록"을 복사 가능한 코드블록으로 출력**한다 (사용자가 반대편 Claude에 붙여넣는 용도):

```
[인계] <이 머신: Mac|Windows> → <상대 머신>
커밋: <해시> <제목> (파일 N개)
변경 요약: <2~3줄 — 무엇을 왜>
테스트: <914/914 통과 | 해당 없음(클라만) | 실패로 미push>
다음에 내가 손댈 곳: <파일·영역 몇 개 — 없으면 "없음(넘김)">
상대 머신에서 할 일:
- /GIJOAS동기화 로 받기
- <서버 변경 시> Windows면: 검토 후 /GIJOAS배포 (운영 반영 여부는 사용자 결정)
- <서버 변경 시> Mac이면: update-dev-mac.sh
- <클라 변경 시> Windows에서: 검토 후 /GIJOAS게시 (게시 여부는 사용자 결정)
주의사항: <있으면 — 의존성 변경, 마이그레이션, 행동 변화 등>
```

「다음에 내가 손댈 곳」을 왜 적나(2026-08-09 신설): 그날 Mac과 Windows가 **같은 문제를
동시에 고쳤다** — 개인키 감시 자동화를, 서로 모른 채. 파일이 안 겹쳐 rebase로 끝났지만
**운이 좋았을 뿐**이고, 한나절 작업이 겹쳤다. 인계는 「내가 한 일」만 적고 「내가 이어서 할 일」은
안 적는 형식이라 상대가 비켜 갈 수가 없었다.
- 확정된 계획이 아니어도 적는다 — 「아마 라우팅 쪽」 정도면 상대가 그 근처를 피한다.
- 넘기고 손 뗄 거면 **"없음(넘김)"이라고 분명히** 적는다. 빈칸은 「모른다」로 읽혀 상대가
  또 비켜 가느라 아무도 안 하는 자리가 생긴다.
- 긴급 건을 받아 계획이 바뀌면 **다음 인계에서 갱신**한다. 오래된 예고가 더 나쁘다.

역할 규칙(변하지 않음): 게시(/GIJOAS게시)와 운영 배포(/GIJOAS배포 실행)는 Windows 담당. Mac은 hub push까지. GitHub(origin)는 사용자 명시 요청 시만.
