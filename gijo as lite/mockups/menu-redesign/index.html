메뉴 대개편 — 시안 3종

요청: 메뉴를 아주 간소화하고, 왼쪽 메뉴의 서브메뉴로 모든 기능을 옮기고, 오른쪽 화면에서 그 기능을 확인·입력하게. 지금은 24개 기능이 페이지마다 흩어져 전체 페이지 이동을 하지만, 셋 다 왼쪽에서 고르면 오른쪽만 바뀌는 한 화면(마스터-디테일) 구조입니다.

현재 4대분류·12그룹·24기능 → 간소화안 3대분류로 묶고 하위에 전체 기능 배치. 아래 오른쪽 화면은 예시로 "자산 등록" 기능의 입력칸을 보여줍니다.

· 왼쪽에서 기능을 고르면 오른쪽만 바뀜(전체 페이지 이동 대신). 오른쪽엔 그 기능의 입력칸·목록·결과.
· 요청하신 "설명 페이지 + 링크"는 별도 reference-page.html 시안으로 만들었습니다 — 모든 기능의 입력칸을 표로 리스트화하고 각 기능으로 바로 가는 링크 제공.
· 구현 범위 주의: 지금은 페이지마다 별도 HTML(전체 이동)이라, "오른쪽만 바뀌는" 진짜 한 화면 셸로 가려면 구조를 크게 바꿔야 합니다. 우선 ①왼쪽 메뉴만 3대분류+서브메뉴로 재편(저위험) → ②설명 페이지 추가 → ③단계적으로 오른쪽 뷰 통합(고위험) 순서를 권장합니다.
