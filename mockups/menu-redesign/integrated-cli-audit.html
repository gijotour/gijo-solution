① CLI 터미널 — 아래 패널. 담당자 PC의 PowerShell을 직접 띄움(수동 실행은 자유). 허용목록에 있는 안전한 명령(nmap·scan 등)만 바로 실행되고, 목록 밖·위험 명령은 차단. 챗봇이 제안한 명령(예: 원격도구 설치)은 곧바로 실행하지 않고 결재판처럼 승인/거부를 받은 뒤에만 실행.
② 오른쪽 숨기기 — 오른쪽 "작업 세션" 패널의 ⏵ 버튼으로 접기/펴기(상태 기억). 접으면 가운데 작업 화면이 넓어짐.
③ 작업 기록 — 레일의 📜. 터미널 실행·챗봇 승인·쓰기 작업·차단이 전부 한 타임라인에 남음(아래).

구현 시 보안 설계(허용목록·담당자 PC 기준)
· 터미널은 Electron 앱 안에서 담당자 PC의 셸을 pty로 실행(node-pty). 원격 대상은 담당자가 친 명령(ssh 등) 안에서만 — 앱이 원격에 직접 붙지 않음.
· 허용목록: 관리자만 편집. 정규식/명령 화이트리스트로 관리(예: nmap, winget install <승인패키지>, 조회성 Get-*). 목록 밖은 실행 전 승인 필수, 위험 패턴(Remove-Item -Recurse, rm -rf, format 등)은 항상 차단.
· 챗봇 연결은 기존 결재판(사람 승인) 재사용 — AI가 명령을 제안만, 실행은 사람이. 자동 실행 없음.
· 모든 실행·승인·차단은 작업 기록에 강제 기록(끌 수 없음) — ①과 ③이 짝.
