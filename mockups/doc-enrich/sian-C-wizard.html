단계별 위저드 — 저장 전에 사람이 검토·수정

소스 → 방식 → 미리보기(번역 결과·추출된 관계를 사람이 확인·수정) → 저장. AI가 만든 것을 그대로 넣지 않고 사람이 한 번 검수하고 저장하므로 품질·정확도가 가장 높습니다. 외부 생성물 검증 원칙과도 맞습니다.

2. 방식 ✓
3. 검토·수정
4. 저장
👁 미리보기 — 저장 전 확인 ☁ 클라우드(Gemini)로 번역됨
Tenable SC · "진단 파일 로그 옵션" 섹션. 번역과 추출된 관계를 확인하고, 틀린 게 있으면 고친 뒤 저장하세요.
