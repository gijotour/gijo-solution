📄 표준 자동 점검 및 조치 스크립트 프리뷰 (KISA 주요정보통신기반시설 기준)
#!/bin/bash
# ========================================================
# KISA 주요정보통신기반시설 기술적 취약점 조치 스크립트
# 대상: Rocky / RHEL Linux | 생성: GIJO Security Suite
# ========================================================

echo "[*] 1. root 원격 접속 제한 점검 (sshd_config)"
sed -i 's/#PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
systemctl restart sshd
echo "[+] PermitRootLogin -> NO 적용 완료"

echo "[*] 2. 기본 umask 022 설정 점검"
echo "umask 022" >> /etc/profile

echo "[*] 3. 주요 기밀 파일 권한 통제 (shadow, passwd)"
chmod 600 /etc/shadow
chmod 644 /etc/passwd

echo "[+] 모든 KISA 필수 조치가 성공적으로 이행되었습니다."
