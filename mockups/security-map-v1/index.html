① 메뉴는 보기용, 지시는 대화창 — 지도의 모든 단추는 「대화창에 묻기」로 끝납니다. 지도에서 직접 바꾸는 것은 없습니다.
② 클릭 한 번 = 데이터 — 타일 클릭이 끝입니다. 새 창도, 메뉴 이동도 없습니다.
③ 절차 띠 유지 — 맨 위 5단계는 그대로. 지도는 「①발견·②우선순위」를 그림으로 만든 것입니다.
