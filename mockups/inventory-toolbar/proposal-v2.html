바뀌는 것
  • 툴바 2행 → 1행(검색 · 카테고리 · 출처 · 위험·상태 · 정렬) + 하단 줄에 표시 항목(컬럼) 칩 — ✕로 숨기고 ＋로 추가
  • 좌측 카테고리 트리 제거 → 표 전체 폭 + 카테고리 컬럼으로 표시
  • 적용된 필터 칩 줄 신설 — 걸린 게 없으면 안 보임
  • 정렬을 필터와 분리(현재는 "가장 급한 결손" 문구로만 안내)

  • CSV 내보내기·탐지 결과 가져오기·자산 등록
