아직 구현되지 않은 기능입니다6.4절 로드맵
Finding 확인 → 승인 → SBOM 반영 파이프라인
프로젝트 문서 6.4절("보안담당자 결과 확인 → SBOM 형태 정리")에서 언급된 승인 워크플로우입니다. 지금은 스캔으로 나온 finding이 바로 자산의 현재 위험 상태(asset.findings)에 반영되고 SBOM 생성 시 그대로 참조됩니다 — "확인 완료" 처리한 것만 선별해서 반영하는 승인 단계는 서버에 아직 없습니다. 이 단계를 추가하려면 finding별 승인 상태를 저장할 스키마와 승인/반려 API가 먼저 필요합니다.
