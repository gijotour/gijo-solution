⚙설정
단기 · 장기 기억
단기 기억(대화 이력) · 장기 기억(RAG 지식 베이스) · 학습(파인튜닝) — 세 단계로 고객사 데이터를 기억하고 학습합니다.
기억 및 학습 개념 비교
대화 컨텍스트(단기), 로컬 벡터 DB(장기), QLoRA 파인튜닝(뇌 학습)의 아키텍처적 차이점
구분 단기 기억 (Conversation Context) 장기 기억 (RAG / LanceDB) 파인튜닝 (QLoRA / 학습)
핵심 개념 현재 진행 중인 대화 내용을 기억 외부 도서관에서 문서를 찾아보기 뇌 세포(모델 가중치)를 직접 훈련하여 암기
대상 기술 서버 인메모리 대화 이력 (에이전트별 최근 10턴, 채팅 시 자동 주입) LanceDB (로컬 벡터 데이터베이스) 모델 가중치(Weights) 자체 업데이트
현실 비유 메모장에 받아적으며 대화하기 필요할 때 서가에서 백과사전 찾기 지식을 완전히 학습하여 머릿속에 내재화
정보 업데이트 서버 재시작 시 휘발됨 (의도된 설계) DB에 파일 추가 시 즉시 반영 (매우 쉬움) 데이터셋을 구축하여 재학습 필요 (시간 소요)
장기 기억 — 문서 수집 (RAG)
서버가 LanceDB에 청크·임베딩해서 저장합니다 (여러 클라이언트가 같은 지식 베이스를 공유). 수집된 지식은 채팅 시 관련 내용이 자동으로 참고 자료로 주입됩니다.
장기 기억 — 지식 질의
수집된 문서에서 질문과 가장 관련 있는 구절을 검색합니다.
학습 — ① 데이터셋 만들기
보안 문서를 붙여넣으면 로컬 LLM이 Q&A 쌍으로 변환합니다. 검토 후 저장하면 파인튜닝 입력(data/datasets/<ID>.json)이 됩니다.
학습 — ② 파인튜닝Unsloth QLoRA
에이전트를 특정 데이터셋으로 파인튜닝해 내재화된 지식으로 만듭니다.
서버가 scripts/finetune_unsloth.py(Unsloth QLoRA, 베이스: 제품 확정 모델)를 실행해 진행률을 WebSocket으로 스트리밍합니다. GPU 머신에 pip install unsloth가 선행돼야 하며, 결과물은 outputs/<데이터셋ID>/lora-adapter에 저장됩니다. 학습 후 서빙 반영은 서버에서 python scripts/export_gguf.py --adapter outputs/<데이터셋ID>/lora-adapter --model-id <새모델ID> 실행 → 에이전트 AI 화면에서 그 모델 ID로 엔진 시작.
