학습 · 고급
문서로 AI를 직접 훈련시켜 아예 외우게 해요. 시간과 GPU가 필요하지만 가장 강력합니다.
👇 아래 "학습" 섹션 (GPU 필요)
🔧 기술 상세 보기 (단기=대화 이력, 장기=LanceDB RAG, 학습=QLoRA 파인튜닝)
구분단기 기억장기 기억학습
기술서버 인메모리 대화 이력 (에이전트별 최근 10턴, 채팅 시 자동 주입)LanceDB 로컬 벡터 DB (RAG)QLoRA 파인튜닝 (모델 가중치 업데이트)
지속성서버 재시작 시 휘발파일 추가 시 즉시 반영데이터셋 구축 후 재학습 필요
📚 장기 기억 · 문서 올리기
사내 문서를 올리면 채팅할 때 자동으로 참고합니다. "전체 공유"는 모든 에이전트가, 특정 에이전트를 고르면 그 에이전트만 봅니다. (기술: LanceDB에 청크·임베딩 저장)
또는 서버에 이미 있는 파일 경로로 직접 수집
💡 이 문서들, RAG로 쓸까 학습(파인튜닝)으로 쓸까? — 활용 가이드
📚 그냥 참고만 하면 됨 → 장기 기억(RAG)이 더 쉬움
최신 위협 전망·침해사고 사례처럼 "찾아보게만" 하면 되는 자료는 위 문서 올리기에 넣으세요. 재학습 없이 즉시 반영되고, 문서가 바뀌면 다시 올리면 끝입니다.
🎓 AI가 체화하게 하려면 → 학습(파인튜닝)
한국식 사고대응 문체, 보고서 서식, 판단 방식 자체를 AI에 각인시키려면 아래 학습을 쓰세요. GPU와 시간이 필요합니다.
문서별 추천 대상 에이전트 (학습 후 → 모델 내보내기 → 에이전트 AI 화면에서 그 에이전트에 할당)
· 해킹진단 사례·침해사고 분석 → 침투테스트·분석 에이전트
· 사이버 위협 전망·동향 보고서 → CTI·분석 에이전트
· 침해사고 대응 보고서 → 리포트 에이전트 (보고서 문체 학습)
🎓 학습 · ① 데이터셋 만들기
기술문서·보안 규정을 넣으면 로컬 LLM이 학습용 Q&A 쌍으로 자동 변환합니다. PDF·HWPX·텍스트 파일을 여러 개 올리거나 직접 붙여넣으세요. 검토 후 저장하면 파인튜닝 입력이 됩니다. 실제 대화 자동 수집 → 학습 → 배포까지 한 번에 도는 🔄 헤르메스 학습 루프도 확인해보세요.
🎓 학습 · ② 파인튜닝GPU 필요 · Unsloth QLoRA
①에서 만든 데이터셋으로 AI를 훈련시켜 지식을 아예 외우게 합니다. 진행률이 실시간으로 표시됩니다.
서버가 scripts/finetune_unsloth.py(Unsloth QLoRA, 베이스: 제품 확정 모델)를 실행해 진행률을 WebSocket으로 스트리밍합니다. GPU 머신에 pip install unsloth가 선행돼야 하며, 결과물은 outputs/<데이터셋ID>/lora-adapter에 저장됩니다. 학습 후 서빙 반영은 서버에서 python scripts/export_gguf.py --adapter outputs/<데이터셋ID>/lora-adapter --model-id <새모델ID> 실행 → 에이전트 AI 화면에서 그 모델 ID로 엔진 시작.
