왜 전부 발주사 GPU에서 도는가

학습배제의 가장 강한 증빙

외부 API는 "재학습에 안 쓴다"는 계약·설정 증빙이 필요합니다(AQR-09). 로컬 구동은 나갈 통신 자체가 없습니다. 증빙 = 망 구성도 + 외부 발신 차단 로그.

비용 고정 · 종속 차단

글자 수 단위 과금이 없어 질의량이 늘어도 월 비용이 고정(AQR-10). 모델은 표준 모델 파일(GGUF) — 발주사가 직접 교체·재구동 가능(4.8 개방성).

3초를 우리가 통제

외부 API의 네트워크·대기열 변동이 사라지고 지연 전 구간이 내부에 있어 단계별 계측·통제 가능(PER-01·05). 장애 시 자동 재기동은 자사 제품 운영 기능(PER-06).

모델 채택 절차도 제안의 일부: 특정 모델을 못박지 않고, G2(4주차)에 후보 2~3종(Qwen3-Next-80B, gpt-oss-120B 등 Apache 2.0 계열)을 동일 평가셋으로 공개 비교해 발주사와 채택 확정. 한국어 최상위 EXAONE은 비상업 라이선스라 기본 구성에서 배제하고 사유를 명시합니다(AQR-01 라이선스 공개 원칙).
